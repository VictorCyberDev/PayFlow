# Global Financial Authority Network — local demonstrator

The M60 demonstrator proves architecture, not adoption. A financial action originates in an external assistant platform, uses an identity context from another provider, consumes a bounded Authority assertion from an independently modelled issuer, receives an independent verifier verdict, executes through a replaceable rail adapter, reconciles a deliberately ambiguous post-effect timeout through lookup only, and emits portable Proof that a standalone verifier can validate.

The beneficiary does not need to open PayFlow directly. The constant is the financial-authority semantics: exact action, bounded amount/currency/action kind, issuer trust, verifier binding, one-time grant, idempotency, UNKNOWN preservation, reconciliation and Proof.

The rail used by the local demonstrator is a deterministic simulator and is not a live provider capture. Global merchant adoption, formal network membership, legal enforceability and production federation are external outcomes and are not claimed.
