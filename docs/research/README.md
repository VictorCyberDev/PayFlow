# Research workstream (internal)

**Status: no customer research has been done.** No interviews, usability sessions, surveys or observations have taken place, and nothing in this folder may be quoted as customer evidence. The documents here are of three kinds, and each says which it is:

- **Plan**: what would be done and how results would be judged. Contains no results.
- **Hypothesis**: a belief held by the builder, stated so it can be proven wrong.
- **Internal review**: an expert walk-through by the builder (not a user, not independent). It finds things to fix; it does not show that users succeed.

Competitive review is **not performed**: it needs sourced facts about real products, and none were gathered. The method is in `USABILITY-TEST-PLAN.md` appendix.
