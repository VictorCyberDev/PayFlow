## Verification notes that matter

- **Mutation evidence.** Disabling the rail's grant-expiry check makes `crash-after-grant` and `crash-after-provider-create` fail; making the Gateway lifecycle check unreachable makes the lifecycle scenarios and three M7 tests fail. The injector was changed back each time.
- **Previously tautological checks removed.** The M14 reference test used `actual: scenario.expected` and the M48 suite used `run: () => true`. Both are replaced by drivers of production code; `UNSAFE` can never equal an expected outcome.
- **Defects found by actually running the branch** (none were visible in the original ledger-less hand-off): migration 017 referenced a non-existent table (`reservations`) so **every** PostgreSQL integration test failed on a fresh database; two prettier failures; 36 lint and 4 type errors; Gateway had no revoked/suspended Authority check; A2A had no replay/audience evaluation; `Idempotency-Key` was documented in OpenAPI but never implemented (removed; `nonce` is the replay key).
- **Not claimed.** No live provider capture, no customer, pilot, partner, audit, certification, standards participation, app/registry publication, or adoption. Anything `BLOCKED_*` above is a real external step.
