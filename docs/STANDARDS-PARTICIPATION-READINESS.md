# Standards-body participation readiness

Status: **COMPLETE_LOCAL / BLOCKED_EXTERNAL** for actual participation, membership, invitation, acceptance or endorsement.

## Position

Autonomous systems need a transport-neutral financial-authority layer between intent and consequential execution. Existing identity, policy, commerce and agent protocols can carry context, but no transport assertion should silently become permission to move money.

## Contribution proposal

A minimal interoperability profile should standardize: principal/agent binding, bounded Authority representation, monotonic delegation, request/audience binding, runtime revalidation, one-time execution capability semantics, revocation, replay resistance, UNKNOWN outcomes, reconciliation and independently verifiable Proof.

## Existing-protocol relationship

MCP and A2A are agent interoperability transports. OAuth/OIDC and AuthZEN contribute identity/authorization patterns. AP2, ACP and UCP contribute agentic commerce/payment context. PayFlow's proposed profile sits at the financial-authority boundary and maps these protocols without making any one of them mandatory.
