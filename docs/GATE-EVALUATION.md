Responsive and accessibility acceptance (local static export, Chromium): **44 routes × 6 widths (320, 375, 430, 768, 1024, 1440) = 264 page
checks, 0 failures** after one real defect was fixed (a scrolling table on `/enterprise/` that a keyboard could not reach). Checked: horizontal
overflow, one h1, language, one main landmark, axe WCAG 2.0/2.1/2.2 A+AA, skip link as first Tab stop and moving focus into `<main>`, a visible focus
indicator on every Tab stop, no focus trap, 24 px touch targets, no infinite animation under reduced motion, and the verifier by keyboard alone
(`scripts/a11y-acceptance.mjs`, in CI). **Not** done: the same review on a deployed host, a screen-reader pass by a person, colour-contrast beyond axe's
automated rules.

### What closes Gate A (owner actions; each needs a secret or changes who can reach the service)

1. **A public host on a separate database** (`docs/GATE-A-PUBLIC-HOST.md`): a new empty Neon project, `db/migrations/001–023` and
   `db/roles/least-privilege.sql`, environment variables set in the Vercel dashboard (values never pass through this session), Vercel
   Authentication off for that project's Production, `PAYFLOW_PUBLIC_SANDBOX=true`, and the canonical origin set in `apps/console/lib/site.ts`.
2. **A real, monitored security contact.**
3. Then run `node --import tsx scripts/stranger-journey.mjs <public origin>` and the accessibility script against it, and record the result.

Not blockers for the internal product but still open: a **timed run by someone who did not build PayFlow** (the under-five-minutes goal is
unmeasured), and **counsel review** of Terms, Privacy and AUP (drafts are marked as such).

Public-launch controls that exist in source: per-address and global sandbox start limits that fail closed, per-credential request limits,
isolated `sbx_` tenants on a simulated rail that real organisations can never reach, one-hour credentials, per-organization and global pauses,
an append-only audit trail. Not built: automatic expiry cleanup of sandbox tenants, alert delivery.
