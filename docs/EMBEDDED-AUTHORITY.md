# Embedded Authority

Platforms may embed Authority creation without making UI state financial truth. An embedded session is tenant-, environment-, principal-, template- and time-bound. It can produce a reviewed **candidate** Authority only.

Activation remains an authenticated server-side transition that revalidates organization, sponsor/principal, template, constraints and current lifecycle state. A hosted widget or white-label client cannot self-activate Authority and cannot receive unrestricted payment credentials.

Headless integrations should use the same Gateway and Proof contracts. Events may report candidate creation, activation, revocation and Proof availability, but event delivery does not redefine durable Authority state.
